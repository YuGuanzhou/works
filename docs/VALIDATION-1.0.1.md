# 1.0.1 BOSS 登录刷新修复验证

日期：2026-09-09。环境：Windows x64，Python 3.11.6，PyInstaller 6.22.2。

## 改动与依据

- BOSS 改用 Patchright 1.62.3 驱动，使用可见 Chrome / Edge 和浏览器原生窗口尺寸；其他招聘平台保留 Playwright。
- 已打开的登录页、验证页保持当前位置；只有明确识别为未登录时才进入登录入口，避免未知状态触发二次跳转。
- 适配当前 BOSS 首页 `a.header-login-btn` 和 `/web/user/` 登录路由，修复扫码入口选择器。
- 主框架连续刷新、重定向或从 BOSS 返回空白页时停止自动操作并显示提示；不记录 URL 查询参数，不自动破解验证码或持续重试。
- 新版启动时识别同端口的旧版服务并提示关闭，避免打开旧页面却误以为已升级。

参考：[上游刷新问题讨论](https://github.com/loks666/get_jobs/discussions/250)、[Patchright 官方说明](https://github.com/Kaliiiiiiiiii-Vinyzu/patchright-python#patches)。驱动检测只是可能诱因，本次没有证明网站内部的具体判定机制。
