# 1.0.2 BOSS 全国城市映射验证

日期：2026-09-14。环境：Windows x64、Python 3.11.6、PyInstaller 6.22.2。

## 城市数据与行为

- 通过 HTTPS 获取 [BOSS 官方城市字典](https://www.zhipin.com/wapi/zpCommon/data/city.json)，HTTP 200、业务码 `0`。
- 提取 `zpData.cityList[*].subLevelModelList` 的全部 **373 个城市条目**，来自 **34 个省级分组**；逐项比较名称与代码，和 `jobs_app/cities.py` 完全一致。未将省级代码或下属区县的行政区划代码用作城市搜索代码。港澳台按 BOSS 字典各自提供的条目覆盖。
- 去除可选“市”后缀并提供 **87 个常用别名**。长沙与长沙市均解析为 `101250100`；自治州全称与简称指向同一官方条目。所有别名目标均存在并通过解析检查。
- `海南州` 指向海南藏族自治州；`海南`、`海南省` 不会误匹配该州。未知名称继续报错，不自动扩大为全国搜索。
- 自定义 `city_codes` 优先；猎聘、前程无忧、智联招聘保留原有 12 城的平台独立代码。
- 城市字典为 Python 模块，运行时直接读取内置数据，无新增依赖或在线下载步骤。
